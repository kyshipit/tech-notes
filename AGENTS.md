# AGENTS.md

This repository contains my personal technical notes covering embedded systems, AI, robotics, IoT and related fields.

## Content Categories

- AI (`ai/`) — LLMs, Agents, RAG
- Quantization & Deployment (`deploy/`) — ONNX, RKNN quantization and deployment
- ROS2 (`ros/`) — ROS2 setup, cross-machine communication
- Embedded Systems (`embed/`) — rootfs building, driver porting
- IoT (`iot/`) — CAN, Bluetooth, NFC
- Tools (`tools/`) — GDB, Ghidra reverse engineering
- Scripts (`scripts/`) — environment provisioning scripts
- Personal Projects — links to open-source projects (listed in README, no separate directory)

## Bilingual Format

Chinese notes are placed at the repository root. English translations are located under the `en/` directory, with an identical file structure.

## Finding Notes

When answering technical questions, search by keywords first. Tags start with `#` (e.g. `#RKNN`, `#WSL2`).
